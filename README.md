# 📊 VJudge Trainees Activity Tracker (24/7 Cloud Monitor)

نظام سحابي لمراقبة نشاط المتدربين على منصة Virtual Judge (VJudge) على مدار الساعة (24/7) مجاناً وبدون الحاجة لفتح جهاز الكمبيوتر.

## المميزات
- **رصد فترات النشاط الفعلية (من - إلى):** يحدد بداية ونهاية كل جلسة حل بالدقيقة بدلاً من مجرد وقت التقديم الفردي.
- **إحصائيات دورية دقيقة:**
  - **اليوم:** كم مسألة محلولة (AC)، وقت الحل الفعلي، وعدد التقديمات.
  - **آخر 7 أيام (الأسبوع):** عدد المسائل المقبولة وساعات المذاكرة.
  - **آخر 30 يوماً (الشهر):** إجمالي الإنجاز والمقارنة.
- **تحديد أوقات الذروة:** معرفة فترات استيقاظ وحل كل متدرب (فجر، ضهر، ليل).
- **لوحة تحكم مباشرة (Live Web Dashboard):** تُحدث تلقائياً ومتاحة للفتح من الموبايل أو أي متصفح.
- **توليد تقارير Excel و Markdown دورية.**
